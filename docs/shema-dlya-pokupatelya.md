# Автопубликация постов в Telegram: схема для покупателя

Черновик продукта. Пустые поля `_____` заполняет покупатель. Пометка «не готово» значит, что этой функции в алгоритме пока нет.

## Как это работает

```
[1. Подготовка поста]     [2. Очередь]          [3. Публикатор]                 [4. Канал]
 вы или ИИ пишет текст  →  папка outbox/      →  n8n раз в N минут:          →  Telegram-канал
 + картинка                в GitHub             • берёт пост, если время пришло
 (ИИ-генерация —            имя файла =          • проверяет белый список
  не готово)                дата и время         • соблюдает паузу между постами
                                                 • отправляет
                                                        │
                              ┌─────────────────────────┴───────────────┐
                              ▼                                         ▼
                        sent/ — архив со ссылкой         failed/ — пост целиком + причина
                                                         + сообщение владельцу в Telegram
```

Главное правило: пост удаляется из очереди только после того, как сохранена его копия.

### Блок 6. Итоги недели и навигатор с закрепом

Работает у автора с 19.10.2026: «Человек VS ИИ» ([итоги](https://t.me/chelovek_vs_ai/42), [навигатор](https://t.me/chelovek_vs_ai/43)), «Он рядом» ([итоги](https://t.me/ryadom_repetitor/170), [навигатор](https://t.me/ryadom_repetitor/171)). Сейчас этот блок выполняет ассистент через бота, в сценарии n8n его пока нет (не готово).

```
[1. Поиск по промпту]   →  [2. Черновик]           →  [3. Проверка автором]  →  [4. Публикация]          →  [5. Навигатор]
 новости за 7 дней        топ-10: заголовок,          «да» или правки            HTML-разметка,              ссылка на итоги
 по темам канала          1–2 фразы, «что это          без «да» пост              без превью ссылок           в раздел «📰 Итоги недели»,
 только первоисточники    значит для вас»,             не выходит                                              закреп без уведомления
                          ссылка на источник
```

Правила:
1. Каждая новость — со ссылкой на первоисточник или крупное СМИ; дата в пределах недели. Пересказы старых исследований не берём.
2. Пропорция задаётся под канал: например, 5–6 новостей из России и 4–5 мировых, или только российские.
3. Публикация только после явного «да» автора.
4. Навигатор обновляется так: новый пост с разметкой → закреп без уведомления → удалить старый навигатор и служебное сообщение «закреплено». Редактировать навигатор через бота нельзя: при правке теряется разметка, и в тексте видны `<b>` и `<a>`.
5. Каждая публикация записывается в `sent/` со ссылкой.

## Функции бота, которые пока не используем

Бот публикатора может больше, чем отправлять текст. В таблице — что доступно уже сейчас и что можно добавить в n8n запросом к Telegram Bot API.

| Функция | Чем полезна | Где есть |
|---|---|---|
| Кнопки под постом | «Попробовать», «Навигатор», «Записаться» — кликабельная кнопка вместо ссылки в тексте | Сейчас и в n8n |
| Именные пригласительные ссылки | Отдельная ссылка на каждое письмо админу или площадку, видно, откуда пришли подписчики. Подходит для проверки спроса | Сейчас |
| Число подписчиков | Автоматическая цифра в недельном отчёте автору: было / стало | Сейчас |
| Альбом из 2–10 картинок | Карусели и пошаговые схемы одним постом | Сейчас |
| Голосовые и видеокружки | Живой голос автора, разбор за 1 минуту | Сейчас |
| Тихая публикация | Посты вечером и ночью без звука у подписчиков | Сейчас, используем для закрепа |
| Пересылка между каналами | Новость для обоих каналов — переслать с указанием источника | Сейчас |
| Закреп итогов на неделю | Закрепить итоги, через 7 дней снять — навигатор остаётся | Сейчас |
| Опросы | Вопрос к читателям в один клик, бот получает итоги голосования | Через n8n (не готово) |
| Уведомления о комментариях | Бот видит комментарии в группе обсуждения и присылает автору новые | Через n8n, нужна группа обсуждения с ботом (не готово) |

Чего бот не умеет: видеть просмотры и реакции на постах канала. Эти цифры есть только в статистике Telegram у владельца.

## Рекомендации по конфигурации

| Конфигурация | Кому | За | Против |
|---|---|---|---|
| Минимум: n8n Cloud + GitHub + Telegram | Без сервера и терминала | Не нужен сервер и SSH. Тариф Starter: 20 € в месяц при оплате за год, 2 500 запусков в месяц ([n8n](https://n8n.io/pricing/)) | Опрос каждые 2 минуты — около 21 600 запусков в месяц, это больше лимита. Нужен интервал 30 минут (около 1 440 запусков). Оплата из РФ может быть сложной |
| Свой VPS (как у автора) | Готов к терминалу | Без лимита запусков: Community-версию можно ставить на свой сервер бесплатно ([G2](https://www.g2.com/products/n8n/pricing)). У автора хватает 1 ядра и 2 ГБ памяти | Настройка на 2–3 часа, обновления и безопасность — на покупателе |
| Под ключ | Нет времени разбираться | Работает в тот же день | Дороже. Нужен доступ к серверу или пошаговая сессия с покупателем |

Безопасность для любого варианта:
1. Отдельный бот для публикаций, не личный.
2. Токен GitHub только на один репозиторий.
3. Ключи вводятся только в n8n Credentials, автору не пересылаются.
4. Редактор n8n закрыт от интернета.
