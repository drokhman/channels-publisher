# Рубрика «Теория для практика» (поток s34) — план и правила

Решение пользователя 10.11.2026: ещё один поток УЦП — цикл постов по теории, «помаленечку раскрывать, как интересные факты». Три цикла:

1. **Теория игр** — курс Бена Полака, Йельский университет, ECON 159 (запись осени 2007, 24 лекции, открыт: https://oyc.yale.edu/economics/econ-159). Девиз: «Смотри по штуке в день. Чужой ход увидишь раньше, чем его сделают».
2. **Когнитивные искажения** — «когда голова сама тебя обманывает». Даниэль Канеман, «Думай медленно… решай быстро». Девиз: «Заметишь, что сглупил, пока за это ещё не заплатил».
3. **Статистика** — Дарелл Хафф, «Как лгать при помощи статистики». Девиз: «Кривой график раскусишь за секунду».

## Частота и очерёдность
- Три поста потока в неделю: понедельник, среда, пятница (решение пользователя 25.11.2026), входят в обычные 5–6 постов дня (не сверх них).
- Циклы идут по очереди: игры → искажения → статистика → игры… Следующий цикл = тот, что идёт после цикла последнего поста потока (искать `-theory-` в scheduled-ucp/ и scheduled-ucp-done/, последний по дате).
- Следующий номер внутри цикла = наибольший вышедший или стоящий в очереди номер этого цикла + 1. Порядок — по спискам ниже, без пропусков и повторов.
- Анонс потока: `2026-11-10-1637-theory-anons` (сам поток стартует 11.11 постом `theory-games-01`).
- Когда цикл закончился (Хафф — после 10-го поста), его слот в очереди пропускается; продолжение (новую книгу или курс) предложить пользователю и не начинать без его выбора.

`scheduled-ucp/ГГГГ-ММ-ДД-ЧЧММ-theory-games-NN-slug.json`, `…-theory-bias-NN-slug.json`, `…-theory-stat-NN-slug.json` (NN — двузначный номер из списка). Рубрика в библиотеке — «Теория для практика» (правило `-theory-` в config/ucp-topics.json).

## Формат поста
1. Заголовок жирный, без точки, до 70 знаков — сама идея через результат практика («Почему два разумных поставщика вместе теряют деньги»).
2. Строка источника: «Теория игр, ход N. Бен Полак, Йель, <a href=…/lecture-N>лекция N «название по-русски»</a>» · «Искажения, №N. Канеман, «Думай медленно… решай быстро», глава N «…»» · «Статистика, №N. Хафф, «Как лгать при помощи статистики», глава N «…»».
3. Факт, игра или эксперимент из источника — 3–6 коротких предложений, как интересная история: что сделали, что получилось, почему это неожиданно. Цифры и условия — точно как в источнике.
4. «Где это у нас» (жирный подзаголовок) — пример из поставок, закупок, склада, торговли с сетями, управления. Если пример придуман для иллюстрации — так и написать («пример модельный»). Реальный кейс — со ссылкой.
5. «Что сделать» — 1–2 действия с 1️⃣ 2️⃣, проверяемые, на этой неделе.
6. По желанию — короткий вопрос читателям.
7. Строка «Источник: …» со ссылкой на конкретную страницу (лекция на oyc.yale.edu; для книг — страница издания или главы, при цитировании исследования из книги — само исследование, если доступно).
8. Ровно 3 хештега: #НППЦП + 2 из словаря (#планирование #закупки #цепипоставок #логистика #склад #цифровизация #транспорт #ВЭД).

## Проверка
- Каждое утверждение о лекции сверять со страницей лекции и транскриптом на oyc.yale.edu (`/economics/econ-159/lecture-N`). О книгах — с текстом главы (litres/Яндекс Книги ознакомительный фрагмент, Википедия как подсказка, исходные статьи Канемана и Тверски). Не выдумывать цифры экспериментов.
- Пример из практики не должен советовать незаконного: сговор конкурентов о ценах, обмен ценовой информацией между конкурентами — нельзя (антимонопольный закон). Брать примеры внутри компании, между поставщиком и сетью, заказчиком и перевозчиком.
- Не приписывать Полаку, Канеману, Хаффу выводов о логистике: связь с практикой — от редакции.
- Голос и картинка — как в docs/ucp-prompt-v2.md: сухо, без восклицательных знаков, фотореалистичная картинка без текста. До 1000 знаков — фото с подписью; длиннее — фото + отдельный send.
