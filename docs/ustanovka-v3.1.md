# Установка сценария v3.1 (около 30 минут)

Что нового по сравнению со старым сценарием:
- пост удаляется из `outbox/` только после записи в `sent/` или `failed/`;
- время выхода по имени файла, не чаще одного поста в канал за 2 часа;
- ошибка → пост в `failed/`, пауза 60 минут, сообщение вам в личку;
- пустая очередь → одно сообщение вам в личку;
- два формата поста: картинка внутри файла (`image_base64`) и картинка по ссылке (`img`, одно сообщение с крупным превью);
- записи сервера в журнале GitHub подписаны «n8n-publisher (сервер)»;
- все настройки в узле «Настройки».

## Шаги

Где выполнять: **Компьютер** — у вас; **n8n** — в редакторе n8n в браузере.

1. **Компьютер.** Откройте терминал и выполните `ssh -L 5678:127.0.0.1:5678 root@89.19.214.202`.
   Проверка: появилась строка вида `root@ams-1-vm-hc77:~#`. Окно не закрывайте.
2. **Компьютер.** Откройте в браузере `http://localhost:5678`.
   Проверка: виден список Workflows.
3. **Компьютер.** Скачайте файл `n8n-backup/publish-from-github-v3.1.json` из репозитория `drokhman/channels-publisher` (кнопка Download raw file).
   Проверка: файл лежит в «Загрузках».
4. **n8n.** Workflows → Create workflow → меню «…» справа сверху → Import from File → выберите файл.
   Проверка: на холсте 17 узлов, название «Публикация из GitHub в Telegram v3.1».
5. **n8n.** Откройте по очереди узлы «Список outbox», «Скачать пост», «Записать в GitHub», «Убрать из outbox» и в поле Credential выберите ваш ключ GitHub (Header Auth).
   Проверка: у этих четырёх узлов нет красного значка.
6. **n8n.** Откройте узлы «Отправить картинку», «Отправить текст», «Сообщить мне», «Сообщить: очередь пуста» и выберите ваш ключ Telegram.
   Проверка: красных значков на холсте нет.
7. **n8n.** Нажмите Save.
   Проверка: надпись Saved.
8. **n8n.** Вернитесь в список Workflows. У старого сценария «Публикация из GitHub в Telegram» выключите переключатель Active.
   Проверка: старый сценарий серый (Inactive).
9. **n8n.** Откройте v3.1 и включите переключатель Active.
   Проверка: в течение 2–4 минут в личку от бота придёт «очередь outbox пуста» — значит, сервер работает и может вам писать.
10. **Напишите ассистенту «включил».** Ассистент положит в `outbox/` три теста:
    - A — текст вам в личку → должен прийти;
    - B — в канал не из белого списка → не уйдёт, в личку придёт сообщение об ошибке, файл появится в `failed/`;
    - C — картинка по ссылке вам в личку → должна прийти с крупным превью.
    Через ~60 минут после теста B пауза снимется сама.
11. После тестов ассистент переносит очереди из `hold/migrate-v31/` в `outbox/`, удаляет `scheduled/` и выключает автоматизации Perplexity «Отложенные посты в Telegram» и «Публикация постов в „Он Рядом“: 2 в день».

## Откат

Выключите v3.1, включите старый сценарий. Старый сценарий не удаляйте неделю. До отката уберите из `outbox/` файлы с будущей датой: старый сценарий публикует их сразу.
