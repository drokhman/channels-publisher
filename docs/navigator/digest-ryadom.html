Заявление нужно подать до 1 февраля, онлайн — в 53 регионах. → Для вас: напомните выпускникам и родителям о сроке, пока не забыли. «Росбалт», по данным Рособрнадзора 2. ЕГЭ начнётся не раньше 1 июня. Основной период согласовали с окончанием учебного года. → Для вас: в мае можно спокойно доводить слабые темы. «Росбалт» 3. Олимпиадникам ужесточили поступление. Закон одобрил Совфед; ВсОШ это не касается. → Для вас: призёрство остаётся ценным, но без хорошего ЕГЭ не обойтись. РБК 4. ИИ войдёт в учебник информатики. РАН и «Яндекс» добавят в него устройство языковых моделей, промпты и агентов. → Для вас: информатикам стоит заранее разобраться в этих темах. Интерфакс 5. ИИ пробуют в начальной школе. В Подмосковье начали эксперимент под наблюдением психологов и педагогов. Главный принцип — не навредить ребёнку. → Для вас: родители младшеклассников придут с вопросами — будьте готовы объяснить плюсы и риски. «Первое сентября» 6. Задания по математике утверждает совет во главе с ректором МФТИ. → Для вас: спрос на подготовку к профильной математике и физике будет расти. «Новости Mail», по данным РИА Новости 7.
