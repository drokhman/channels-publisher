Итоги недели для репетитора (13–20 ноября) 1. Серьёзных изменений в ЕГЭ-2027 не будет. Музаев пообещал только точечные правки, которые затронут работу комиссий с 2028 года. → Для вас: готовьте по текущим демоверсиям без опасений. Интерфакс 2. Практики в ЕГЭ по физике и химии не будет ещё два года. Экспериментальные задания только начали проверять. → Для вас: выпускникам 2027 и 2028 годов практическая часть не грозит. «Фонтанка» 3. ИИ не проверяет развёрнутые ответы. Компьютер оценивает только краткие ответы, итог всегда за экспертом. → Для вас: учите писать развёрнутые ответы по критериям — их читает человек. Newslab 4. Устный экзамен по истории в 9 классе — с 2028 года. Массовая апробация пройдёт весной 2027-го. → Для вас: нынешним восьмиклассникам понадобится подготовка к устному ответу. «Дети Mail», по данным «Правмира» 5. Итоговое собеседование изменится. С 2027 года — три задания вместо четырёх, зачёт от 10 баллов из 17. Проведут 10 февраля. → Для вас: потренируйте монолог — не меньше 10 предложений за 3 минуты. «Правмир» 6. Известно расписание ЕГЭ-2027. Основной период — 1–19 июня: русский 4 июня, математика 7 июня. Приказы ждут регистрации в Минюсте. → Для вас: стройте план подготовки от этих дат. «Материнство» 7. Кравцов против отмены домашних заданий. Министр призвал делать их самостоятельно, без списывания и нейросетей. → Для вас: домашние задания остаются — и разбор «как решить самому» по-прежнему нужен. «Ведомости» 8. Почти все школьники пользуются нейросетями. По словам Кравцова, в основном американскими, и часто — для готовых ответов. → Для вас: покажите ученику, как проверять ответ ИИ, а не переписывать его. «Фонтанка» 9. На репетитора тратят 9,2 тыс. рублей в месяц. Час стоит около 1000 рублей, подготовка к ОГЭ и ЕГЭ — 1100. 57% родителей хотят, чтобы ребёнок полюбил учёбу. → Для вас: родителям важен не только балл — расскажите, как меняется интерес ребёнка.
