# Ссылки с метками для бота

Подставьте вместо ИМЯ_БОТА username бота без @. Метка после `start=` показывает в /stats, откуда пришёл человек. Можно придумывать свои: латиница, цифры, `_` и `-`, до 64 знаков. Начало метки задаёт ветку: `cvai_` или `ryadom_`.

## «Человек VS ИИ» (руководители)

| Где ставим | Ссылка |
|---|---|
| TenChat, посты | https://t.me/ИМЯ_БОТА?start=cvai_tenchat |
| TenChat, профиль | https://t.me/ИМЯ_БОТА?start=cvai_tenchat_profile |
| Посты канала | https://t.me/ИМЯ_БОТА?start=cvai_channel |
| Подпись в почте | https://t.me/ИМЯ_БОТА?start=cvai_email |
| Конференции, слайд с QR | https://t.me/ИМЯ_БОТА?start=cvai_conf |

## «Он рядом» (репетиторы)

| Где ставим | Ссылка |
|---|---|
| Чаты репетиторов | https://t.me/ИМЯ_БОТА?start=ryadom_chats |
| Посты канала | https://t.me/ИМЯ_БОТА?start=ryadom_channel |
| Сайт onryadom.ru | https://t.me/ИМЯ_БОТА?start=ryadom_site |
| TenChat | https://t.me/ИМЯ_БОТА?start=ryadom_tenchat |

Ссылка без метки (`https://t.me/ИМЯ_БОТА`) тоже работает: бот спросит, что человеку ближе.
