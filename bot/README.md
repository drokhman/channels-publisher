# Бот-воронка для двух каналов: установка (около 1 часа)

## Как работает

Один бот, две ветки: «Человек VS ИИ» для руководителей и «Он рядом» для репетиторов.

1. Человек переходит по ссылке с меткой, например `t.me/ИМЯ_БОТА?start=cvai_tenchat`. Метка говорит боту, какая ветка и откуда пришёл человек.
2. Бот здоровается и просит подписаться на канал.
3. Человек нажимает «Я подписался», бот проверяет подписку и присылает подарок (PDF).
4. Через 1, 2, 3, 4 и 6 дней приходят сообщения цепочки со ссылками на лучшие посты. Только с 10:00 до 20:00 по Москве.
5. В четвёртом и пятом сообщении есть кнопка заявки. Нажатие приходит вам в личку: имя, @username, ветка, откуда пришёл.

Бот работает на том же n8n, что публикует посты, но в отдельном сценарии. Сценарий публикации он не трогает. Сервер не нужно открывать в интернет: бот сам раз в минуту забирает новые сообщения у Telegram.

Бот хранит только Telegram ID, имя, @username, ветку, метку и шаг цепочки. Данные лежат внутри n8n и в репозиторий не попадают.

## Команды владельца (работают только с вашего аккаунта)

- PDF с подписью `gift_cvai` или `gift_ryadom`: сохранить подарок для ветки;
- `/stats`: статистика: сколько пришло по каждой метке, сколько подписались, дошли до конца, оставили заявку;
- `/demo cvai` или `/demo ryadom`: прислать вам всю цепочку сразу, чтобы посмотреть тексты.

Для всех: `/start`: начать, `/stop`: больше не присылать сообщения.

## Шаги

Где выполнять: **Telegram**: в приложении; **Компьютер**: у вас; **n8n**: в редакторе n8n в браузере.

### Часть 1. Новый бот (10 минут)

1. **Telegram.** Откройте @BotFather и отправьте `/newbot`.
   Проверка: BotFather спрашивает имя бота.
2. **Telegram.** Отправьте имя, которое увидят люди, например `Дмитрий Рохман: ИИ и каналы`.
   Проверка: BotFather спрашивает username.
3. **Telegram.** Отправьте username, он должен заканчиваться на `bot`, например `rokhman_ai_bot`.
   Проверка: пришло сообщение со строкой вида `1234567890:AA...`. Это ключ. Никому его не пересылайте, даже ассистенту.
4. **Telegram.** Отправьте BotFather `/setcommands`, выберите нового бота и отправьте одним сообщением:
   ```
   start - Начать
   stop - Больше не присылать сообщения
   ```
   Проверка: BotFather ответил Success.

### Часть 2. Бот в каналах (5 минут)

Бот должен видеть, кто подписан. Для этого он становится администратором без прав.

5. **Telegram.** Откройте канал «Человек VS ИИ» → название канала сверху → Управление каналом (карандаш) → Администраторы → Добавить администратора → найдите нового бота по username.
   Проверка: открылся экран с правами администратора.
6. **Telegram.** Выключите все переключатели прав и нажмите Сохранить (галочка).
   Проверка: бот появился в списке администраторов.
7. **Telegram.** Повторите шаги 5 и 6 для канала «Он рядом».
   Проверка: бот в списке администраторов обоих каналов.

### Часть 3. Сценарий в n8n (15 минут)

8. **Компьютер.** Скачайте файл `bot/bot-voronka-v1.json` из репозитория `drokhman/channels-publisher` (кнопка Download raw file).
   Проверка: файл в «Загрузках».
9. **Компьютер.** Откройте терминал и выполните `ssh -L 5678:127.0.0.1:5678 root@89.19.214.202`.
   Проверка: появилась строка вида `root@ams-1-vm-hc77:~#`. Окно не закрывайте.
10. **Компьютер.** Откройте в браузере `http://localhost:5678`.
    Проверка: виден список Workflows.
11. **n8n.** Workflows → Create workflow → меню «…» справа сверху → Import from File → выберите файл из шага 8.
    Проверка: на холсте 4 узла: «Каждую минуту», «Настройки», «Тексты», «Бот».
12. **n8n.** Двойной клик по узлу «Настройки». В строке `token:` замените `ВСТАВЬТЕ_СЮДА_КЛЮЧ_БОТА` на ключ из шага 3. Кавычки `'` по краям оставьте.
    Проверка: строка выглядит как `token: '1234567890:AA...',`.
13. **n8n.** Закройте узел и нажмите Save.
    Проверка: надпись Saved.
14. **n8n.** Включите переключатель Active справа сверху.
    Проверка: через 2 минуты во вкладке Executions нет красных запусков. Успешные запуски там не сохраняются, чтобы не забивать сервер, поэтому пустой список это нормально.

Важно: проверяйте бота только во включённом состоянии. Кнопка «Execute workflow» запускает тестовый прогон, а он не сохраняет пользователей.

### Часть 4. Подарки и проверка (15 минут)

15. **Telegram.** Откройте нового бота, отправьте ему файл `Битва-мозгов-шаблон-для-руководителя.pdf` и в подписи к файлу напишите `gift_cvai`.
    Проверка: в течение минуты бот ответил «Подарок для ветки cvai сохранён».
16. **Telegram.** Отправьте файл `ИИ-для-репетитора-без-риска.pdf` с подписью `gift_ryadom`.
    Проверка: «Подарок для ветки ryadom сохранён».
17. **Telegram.** Отправьте боту `/demo cvai`, затем `/demo ryadom`.
    Проверка: пришли приветствие, подарок и все сообщения цепочки.
18. **Telegram.** Откройте ссылку `https://t.me/ИМЯ_БОТА?start=cvai_test` (подставьте username бота) и нажмите Start.
    Проверка: пришло приветствие с кнопками «Подписаться» и «Я подписался».
19. **Telegram.** Нажмите «Я подписался».
    Проверка: пришёл подарок. Вы владелец канала, поэтому подписка засчитывается сразу.
20. **Telegram.** Отправьте `/stats`.
    Проверка: строка `cvai / cvai_test: старт 1, подписка 1`.
21. **Напишите ассистенту username бота.** Ассистент подготовит ссылки с метками для TenChat, постов и чатов.

## Если что-то не так

- **Бот молчит больше 2 минут.** n8n → сценарий → Executions: откройте красный запуск, узел «Бот», скопируйте текст ошибки ассистенту. Ключ в ошибке не виден.
- **Ошибка `Conflict: can't use getUpdates method while webhook is active`.** Ключ от бота, у которого уже настроен другой способ работы. Для воронки нужен новый бот.
- **«Пока не вижу подписки», хотя человек подписан.** Проверьте шаги 5, 6 и 7: бот должен быть администратором канала.
- **Откат.** Выключите переключатель Active. Сценарий публикации постов продолжит работать как раньше.

## Как менять тексты

Узел «Тексты». Каждое сообщение лежит между обратными кавычками `` ` ``. Меняйте слова, кавычки не трогайте. `delays`: через сколько часов после подарка приходит каждое сообщение. После правки нажмите Save.
