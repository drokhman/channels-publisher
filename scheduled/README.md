# Отложенные посты

Папка `scheduled/ГГГГ-ММ-ДД/` содержит посты на этот день. Каждый день в 10:00 по Москве автоматизация Perplexity переносит файлы `.json` из папки сегодняшней даты (и всех прошедших) в `outbox/`, после чего n8n их публикует.

Файлы `.md` с пометкой VRUCHNUYU не публикуются автоматически (например, опросы): автоматизация присылает напоминание с текстом.

Чтобы отменить пост, удалите его файл. Чтобы перенести, переложите в папку другой даты.
