# channels-publisher

Закрытый репозиторий для автопубликации постов в каналы.

- `docs/vosstanovlenie-dostupa.md` — инструкция по восстановлению доступа и установке с нуля.
- `outbox/` — посты, согласованные к публикации. n8n забирает их отсюда.
- `sent/` — опубликованные посты со ссылками на сообщения.
- `n8n-backup/` — резервные копии сценариев n8n.

Секретов здесь нет и быть не должно: пароли, токены и ключи хранятся только в личном менеджере паролей.
