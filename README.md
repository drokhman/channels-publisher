# channels-publisher

Закрытый репозиторий для автопубликации постов в каналы.

| Папка | Что в ней |
|---|---|
| `outbox/` | Согласованные посты. n8n публикует их, когда наступает время из имени файла. |
| `sent/` | Опубликованные посты со ссылками на сообщения. |
| `failed/` | Посты, которые не удалось отправить. Файл сохраняется целиком вместе с текстом ошибки. |
| `hold/` | Посты на паузе. n8n эту папку не читает. Чтобы опубликовать пост, перенесите его в `outbox/`. |
| `scheduled/` | Старая схема: автоматизация Perplexity раз в день переносит посты отсюда в `outbox/`. С версией 2 сценария она не нужна. |
| `n8n-backup/` | Резервные копии сценариев n8n. Рабочая версия — `publish-from-github-v3.1.json` (установка: `docs/ustanovka-v3.1.md`). |
| `docs/` | Инструкция по восстановлению доступа. |

Секретов здесь нет и быть не должно: пароли, токены и ключи хранятся только в личном менеджере паролей.

## Время выхода поста (сценарий v2)

Время задаётся именем файла в `outbox/`, по Москве:

| Имя файла | Когда выйдет |
|---|---|
| `2026-10-19-0900-tema.json` | 19 октября в 09:00 |
| `2026-10-19-2130-tema.json` | 19 октября в 21:30 |
| `2026-10-19-tema.json` | 19 октября в 09:00 (время по умолчанию) |
| `tema.json` | сразу |

Правила сценария v2:

- **Не чаще одного поста в канал за 2 часа.** Даже если в очереди накопилось много постов, канал не засыплет. Значение `MIN_GAP_MINUTES` в узлах «Выбрать пост» и «Подготовить».
- **Файл удаляется из `outbox/` только после отправки.** Если Telegram вернул ошибку, пост переносится в `failed/` и не теряется.
- **После ошибки Telegram — пауза 60 минут.** Если сломался ключ бота, очередь не будет перекладываться в `failed/` по одному посту каждые 2 минуты.
- **Короткий пост (до 1 000 знаков) уходит одним сообщением**: картинка с подписью. Длинный — картинкой и отдельным текстом. Пост без картинки — только текстом.
- **Белый список каналов:** `@chelovek_vs_ai`, `@ryadom_repetitor`. Пост в другой канал попадёт в `failed/`.

## Расписание с 20.10.2026

Оба канала: **два поста в день**. Утром — случайное время 08:00–08:45, вечером — случайное время 18:20–18:45 (МСК). Минуты выбираются при постановке поста в очередь и записываются в имя файла: `2026-10-25-0833-cvai-tema.json`. Новые посты ставятся в первый свободный слот после последнего поста канала.

## Формат поста

Два варианта. Картинка внутри файла:

```json
{
  "id": "2026-10-19-0900-tema",
  "channel": "Он рядом",
  "chat_id": "@ryadom_repetitor",
  "text_html": "<b>Заголовок</b>\n\nТекст поста. Разметка Telegram HTML.",
  "image_base64": "…",
  "image_mime": "image/jpeg"
}
```

`image_base64` и `image_mime` необязательны.

Картинка по ссылке — одно сообщение с крупным превью (так оформлены посты «Он Рядом»):

```json
{
  "id": "2026-10-20-1000-ryadom-tema",
  "chat_id": "@ryadom_repetitor",
  "img": "https://iili.io/....jpg",
  "text": "<b>Заголовок</b>\n\nТекст поста"
}
```

Время по умолчанию (если в имени только дата) в v3.1 — 10:00.

## Установка сценария v2

1. Откройте редактор n8n через SSH-туннель.
2. Старый сценарий «Публикация из GitHub в Telegram»: выключите переключатель **Active**.
3. **Workflows → Add workflow → … → Import from File** → `n8n-backup/publish-from-github-v2.json`.
4. В узлах с красным значком выберите учётные данные:
   - «Список outbox», «Скачать пост», «Записать в GitHub», «Убрать из outbox» — GitHub (Header Auth);
   - «Отправить картинку», «Отправить текст» — Telegram, с новым ключом бота.
5. **Save**, затем включите **Active**.
6. Старый сценарий не удаляйте неделю — на случай отката.

## Расписание УЦП (@nscspr)

- Очередь: `scheduled-ucp/ГГГГ-ММ-ДД-ЧЧММ-slug.json` (время московское), формат `{"steps":[{"action":"photo"|"send"|"poll", ...}]}` — действия как в `bot/ucp_commands.py`.
- Время постов: `python3 bot/ucp_times.py ДАТА [5|6] [ЧЧММ]` — 5–6 постов, шаг 60–90 мин, 08:00–18:45, время дня не повторяется (журнал `scheduled-ucp/used-times.txt`).
- После добавления файлов: `python3 bot/ucp_cron.py` — пересчитывает cron в `.github/workflows/ucp-schedule.yml` (один запуск на пост; страховка убрана ради минут Actions). Пушить с токеном, у которого есть scope `workflow`.
- Публикует `bot/ucp_schedule.py`: один пост за запуск, результат — `scheduled-ucp-done/` или `scheduled-ucp-failed/` (message_id, late_min).
- Удалить или исправить вышедший пост — команда в `commands-ucp/` (delete, edit, edit_caption).
